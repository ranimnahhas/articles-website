# Articles Website - CMS Admin Panel

A modern, responsive Content Management System (CMS) for managing articles, categories, and users with a React-based admin dashboard.

## 🚀 Features

- **Dashboard** - Overview with statistics and recent articles
- **Articles Management** - Create, edit, publish, and delete articles
- **Categories Management** - Organize articles into categories
- **Users Management** - Admin user management
- **Rich Text Editor** - Markdown editor for article content
- **Responsive Design** - Works on desktop, tablet, and mobile
- **Dark Mode** - Toggle between light and dark themes
- **Image Management** - Upload and manage article images
- **Pagination** - Efficient data loading for large datasets

## 📦 Installation

### Prerequisites
- Node.js (version 14 or higher)
- npm or yarn
- Backend API (Laravel/PHP)

### Frontend Dependencies

Install all required packages:

```bash
# Core React dependencies
npm install react react-dom react-router-dom

# UI and styling
npm install @uiw/react-md-editor

# Icons (Font Awesome)
npm install @fortawesome/fontawesome-free

# Development dependencies (if not already installed)
npm install --save-dev @vitejs/plugin-react vite
